# Privacy and sharing audit

Reusable code, fictional defaults and the public source lock belong in Git. Credentials, private deployment overlays, production exports, customer records, orders, fulfillment data, internal costs, conversation logs, database backups, uploaded knowledge and indexes do not. `.gitignore` and `.dockerignore` exclude runtime/private data and prevent those directories entering the Node image build context. The DocsGPT build uses its pinned public Git context.

`npm run scan` inspects tracked and untracked shareable text plus reachable local Git history. Findings contain a path/category/line, never the matching credential value. It is a best-effort signature scan, not a proof of secrecy. Review high-entropy values, screenshots/binary files, archives, releases and remote/unreachable history separately with a mature secret scanner before publication. A positive secret finding requires private investigation and credential rotation/revocation; deleting the working-tree file is insufficient because Git history and copies may retain it.

Do not rewrite shared history, publish artifacts, change repository visibility or rotate live keys without explicit authorization. Keep a private incident record for any exposure. This starter's initial local history was empty at audit time; remote-only objects, third-party copies and future commits cannot be certified by that observation. See VERIFICATION.md for the actual audit scope.

Anonymous chat cookies are independent of customer accounts, HttpOnly, signed, SameSite Strict and secure under HTTPS. Redis binds conversation IDs to that session before forwarding them. The gateway fixes its backend and agent, strips client history/control fields, filters SSE data and source URLs, enforces shared limits and fails closed. No browser-persisted conversation history, uploads, microphone or administrative tools are enabled. These controls do not eliminate the need for production penetration tests and appropriate retention.

Messages and retrieved excerpts are sent to the configured external model provider for generation. Its data-handling terms and costs apply. Local embeddings do not mean the whole chat remains local. Disclose this flow to users, establish a retention/deletion policy, and avoid collecting sensitive information. No human receives a conversation unless a separately implemented and verified handoff delivers it.
