# شروع سریع فارسی

این پروژه یک قالب دستیار پشتیبانی است. اطلاعات نمونه دربارهٔ شرکت خیالی «آکمه» است؛ به فروشگاه یا مشتری واقعی وصل نیست. رابط فارسی راست‌به‌چپ و رابط انگلیسی چپ‌به‌راست است.

**هنوز آمادهٔ انتشار عمومی اعلام نشده است.** وضعیت واقعی آزمون‌ها را در [گزارش بررسی](VERIFICATION.md) بخوانید.

## پیش‌نیاز و محل اجرای دستورها

Git و Node.js نسخهٔ ۲۲٫۱۲ یا جدیدتر از شاخهٔ ۲۲ را نصب کنید. ترمینال را در پوشه‌ای باز کنید که فایل `README.md` و `package.json` این پروژه قرار دارد. برای روش Docker، موتور Docker و Compose v2 باید در حال اجرا باشند؛ دست‌کم ۴ گیگابایت حافظهٔ آزاد و حدود ۱۰ گیگابایت فضای دیسک در نظر بگیرید.

```sh
npm ci
npm run setup -- --mode=docker
```

اجرای اول ممکن است چند دقیقه طول بکشد. نصب، پایگاه داده، Redis، سرویس API، پردازشگر پس‌زمینه و صفحهٔ گفتگو را آماده می‌کند. اجرای دوباره نباید تنظیمات، کلیدهای ماندگار یا داده‌ها را پاک کند.

فایل `.env` را **فقط در ویرایشگر محلی خودتان** باز کنید. نشانی سرویس مدل، کلید مجاز و نام دقیق مدل را در `OPENAI_BASE_URL`، `API_KEY` و `LLM_NAME` قرار دهید. کلید یا کل فایل محیط را برای دستیار هوش مصنوعی نفرستید. سپس نصب را دوباره اجرا کنید تا محیط خصوصی کانتینرها به‌روز شود.

```sh
docker compose --env-file .runtime/docker.env ps
docker compose --env-file .runtime/docker.env run --rm web npm run bootstrap
```

موفقیت یعنی سرویس‌ها سالم باشند و پیام ورود دانش خیالی و ساخت عامل پیش‌نویس را ببینید. صفحهٔ `http://localhost:3080` را باز کنید. عامل عمداً تا زمان بررسی و انتشار فعال نیست؛ داشتن دکمهٔ گفتگو به معنی آماده بودن پاسخ‌گویی نیست.

## روش بدون Docker

در macOS یا Linux علاوه بر Node و Git، به uv، Bash، PostgreSQL 16 و Redis نیاز دارید. در Windows از WSL2 استفاده کنید. [راهنمای نصب](INSTALLATION.md) مسیر ابزارها و دستورهای سیستم‌عامل را توضیح می‌دهد.

```sh
npm ci
npm run setup -- --mode=native
npm run services
npm run dev
```

ترمینال آخر را باز نگه دارید. در ترمینال دوم و در همین پوشه:

```sh
npm run doctor
npm run bootstrap
```

پایگاه دادهٔ نمایشی روی پورت `55432` و Redis روی `56379` اجرا می‌شوند تا به سرویس‌های قبلی شما دست نزنند. اجرای تنها رابط کاربری نصب کامل نیست؛ API، پردازشگر، پایگاه داده، Redis و ایندکس دانش لازم‌اند.

## شخصی‌سازی و کمک گرفتن

نام شرکت، رنگ، زبان، وب‌سایت و لینک پشتیبانی در `config/starter.json` هستند. کلیدها در `.env` می‌مانند. دانش واقعی فقط باید از اطلاعات عمومی و تأییدشده باشد؛ رمز، سفارش، مکالمهٔ مشتری، اطلاعات پرداخت یا قیمت داخلی را وارد نکنید.

این متن را می‌توانید به دستیار کدنویسی بدهید:

> فایل AGENTS.md و کد موجود را بخوان. نصب کامل این پروژه را با دادهٔ خیالی بررسی کن. فایل‌ها، تنظیمات و سرویس‌های قبلی را حفظ کن. برای وارد کردن کلیدها فقط محل ویرایش محلی را نشان بده و از من نخواه کلید یا فایل محیط را در گفتگو بفرستم. آزمون‌ها را اجرا کن و روشن بگو چه چیزهایی واقعاً تأیید نشده‌اند.

اگر خطا دیدید، ابتدا `npm run doctor` را اجرا کنید. نام بررسی ناموفق و خطای پاک‌سازی‌شده را به دستیار بدهید. کل فایل `.env`، خروجی خام پایگاه داده یا لاگ مشتری را ارسال نکنید. برای رفع خطا از `docker compose down -v` استفاده نکنید؛ این دستور ممکن است داده‌ها را حذف کند.

مدل، سرور، فضای ذخیره‌سازی، پشتیبان‌گیری و ترافیک ممکن است هزینه داشته باشند. پروژه سرویس پولی نمی‌خرد و پرداخت واقعی انجام نمی‌دهد. راهنمای [هزینه و استقرار](DEPLOYMENT.md) و [حریم خصوصی](PRIVACY.md) را پیش از استفادهٔ عمومی بخوانید.
