# Copy-ready prompts

**Install:**

> Read AGENTS.md and inspect the repository before editing. Install the complete fictional demo using Docker [or native mode]. Preserve existing configuration, services and data. Show where I can enter credentials locally; never ask me to paste API keys or full environment files. Run health, ingestion, widget and relevant security checks. Report each verified and blocked step honestly.

**Configure my organization:**

> Inspect config/starter.json and explain its public fields in plain language. Configure my organization using only the public name, website, verified support link and approved knowledge I provide. Keep credentials private. Preserve Persian/RTL and English/LTR, source boundaries and server-side agent selection. Do not enable public chat until generation, retrieval and citations are verified.

**Troubleshoot:**

> Read AGENTS.md and run safe diagnostics. The failed check is [name] and the sanitized error is [category]. Do not print environment values, raw requests, conversations or database exports. Diagnose the smallest relevant component. Preserve unrelated changes and data. Run a focused regression check after fixing it.

**Update DocsGPT:**

> Inspect source.lock.json, the fork contribution and upstream changes. Propose a reviewed immutable revision that preserves Persian/RTL and existing configuration. Preserve the current checkout and secrets. Check migrations, model/embedding compatibility, widgets, both install paths and rollback before deployment. Do not rewrite history, publish artifacts or change visibility without my explicit authorization.

**Prepare to share:**

> Audit shareable files, reachable history, examples, screenshots and artifacts with redacted findings. Keep organization overlays, exports, indexes and secrets private. Run the clean-checkout verification matrix and report untested platforms and blockers. Flag any suspected credential for rotation. Do not claim a clean pattern scan proves privacy or rewrite shared history automatically.
